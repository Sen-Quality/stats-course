歷史故事 & 數學由來
📜 1733 — Abraham de Moivre

最早由法國數學家 de Moivre 在研究二項分佈的極限時推導出常態曲線，用來近似計算賭博勝負機率。他私下流傳計算表格，從未正式發表。

⭐ 1809 — Carl Friedrich Gauss

高斯在研究天文觀測誤差時，從「最可能的真實值就是使誤差最小的值」這個直覺出發，以最大似然估計（MLE）推導出常態分佈，奠定了現代誤差分析基礎。因此又稱「高斯分佈」。

🔔 中央極限定理（CLT）

為什麼製造業大量用常態分佈？因為 CLT：不論原始分佈形狀，只要樣本數夠大（n ≥ 30），樣本平均數的分佈趨近常態分佈。這是 SPC 管制圖的數學基礎。

自由度（Degrees of Freedom）是什麼？

直覺解釋：n 個數字裡，能「自由變動」的有幾個？

假設你有 3 個數字，平均數已知為 10。這時候前兩個數字可以任意取值，但第三個就被鎖死了（因為總和必須等於 30）。所以自由度 = 3 − 1 = 2。

一般公式：df = n − p，其中 p 是用數據估計的參數個數。

計算樣本標準差 s 時，我們先用數據估計了 x̄（耗掉 1 個自由度），所以 s 的 df = n − 1，分母是 n−1 而非 n。

\[s = \sqrt{\frac{\sum(x_i - \bar{x})^2}{n-1}} \quad \leftarrow \text{分母用 }n-1\text{（無偏估計）}\] 若用 n 當分母，s² 會系統性低估真實的 σ²
用 n−1 才能讓 E[s²] = σ²（不偏性）

圖示：n=3，平均數 = 10，df = 2

df 越小 → 不確定性越高 → t 分佈尾端越厚 → 需要更大的 t 值才能達到顯著。 這就是為什麼小樣本（df 小）比較難拒絕 H₀。

歷史故事 & 數學由來
🍺 1908 — William Sealy Gosset（筆名 Student）

Gosset 是都柏林健力士啤酒廠（Guinness Brewery）的化學師，每次品質實驗樣本數極少（通常 n < 10）。他發現用常態分佈計算時信賴區間嚴重低估不確定性，導致錯誤決策。

📊 為什麼要有 t 分佈？

當 σ 未知且需用 s 估計時，統計量 t = (x̄ - μ)/(s/√n) 不服從常態分佈，而是服從尾端更厚的 t 分佈。尾端越厚 = 需要更極端的觀測值才能拒絕 H₀ = 對小樣本更保守。

🏭 品質工程應用

製造業中量測少量樣本（如 n=5 的子群）就用 t 分佈。信賴區間、配對 t 檢定、迴歸係數顯著性全部依賴 t 分佈。當 df → ∞（大樣本），t 分佈收斂至標準常態。

歷史故事 & 數學由來
🎲 1654 — Pascal & Fermat 的賭注

法國賭徒 Chevalier de Méré 問帕斯卡：「擲骰子 24 次，至少出現一次雙六的機率是多少？」帕斯卡與費馬的通信，奠定了組合機率理論的基礎，也是二項分佈的源頭。

📖 1713 — Jacob Bernoulli

Bernoulli 在遺作《猜測的藝術（Ars Conjectandi）》中正式建立二項定理，並提出大數法則：樣本頻率在大量試驗後趨近真實機率。這本書死後才出版，他等了 20 年。

🏭 品質工程應用

p chart（不良率管制圖）的理論基礎就是二項分佈。每件產品「良品/不良品」= Bernoulli 試驗，n 件的不良數服從 B(n, p)。

📌 案例解析：撲克牌抽 A — 二項 vs 超幾何，哪個對？

「在一副普通的 52 張撲克牌中，抽一張，抽不到 A 的機率是多少？」

二項分佈解法

每次抽取視為獨立的 Bernoulli 試驗，成功機率固定：

\[p = \frac{4}{52} = \frac{1}{13} \qquad n=1, \quad k=0\] \[P(X=0) = \binom{1}{0}\left(\frac{1}{13}\right)^0\!\!\left(\frac{12}{13}\right)^1 = \frac{12}{13} \approx \mathbf{0.923}\]

假設：每次抽取放回（或母體夠大使 p 不變）

超幾何分佈解法

母體 N=52，A 共 K=4 張，抽取 n=1 張，求 X=0：

\[P(X=0) = \frac{\dbinom{4}{0}\dbinom{48}{1}}{\dbinom{52}{1}} = \frac{1 \times 48}{52} = \frac{12}{13} \approx \mathbf{0.923}\]

假設：不放回抽樣，p 會隨剩餘牌數改變

兩種方法結果完全相同，原因：
當 n = 1 時，放回與不放回沒有差別——抽一次根本不存在「後續條件改變」的問題。

差異在 n ≥ 2 才出現：
例如抽 5 張，超幾何會考慮第一張抽走後剩 51 張、第二張後剩 50 張……p 每次都在變，這才是超幾何 vs 二項的真正分野。

二項分佈：每次試驗獨立，p 固定（放回抽樣）
超幾何分佈：不放回抽樣，p 隨抽取而改變（有限母體）

平均發生率 λ 3
\[P(X=k) = \frac{e^{-\lambda}\,\lambda^k}{k!}\] \[\mu = \sigma^2 = \lambda\]

法國數學家 Poisson 在研究陪審團錯誤定罪機率時，發展出這個分佈。他試圖回答：「法院在 n 次審判中，真正冤枉好人的次數 k 的機率是多少？」

🏭 品質工程應用

⚙️ 1939 — Waloddi Weibull

瑞典工程師 Weibull 在研究滾珠軸承疲勞壽命時，發現沒有任何現有分佈能夠描述材料強度的「最弱連結」特性。他創造了這個靈活分佈，1951 年發表於 ASME Journal，當時遭到強烈質疑，評審認為「太過任意」。

🛁 浴缸曲線（Bathtub Curve）

韋伯分佈之所以強大，是因為 β 值對應到著名的浴缸曲線三個階段：
β < 1 → 早夭期（初始缺陷，Burn-in 篩選）
β ≈ 1 → 偶發期（隨機失效）
β > 1 → 磨耗期（老化失效，PM 時機）

🏭 品質工程應用

可靠度工程（Reliability Engineering）的核心工具。IATF 16949 中對安全零件的壽命驗證，以及保固期設定、預防保養（PM）週期計算，都需要韋伯分析。

卡方分佈的來源與品質工程應用
📐 數學由來

若 Z₁, Z₂, …, Zₖ 為獨立標準常態，則 χ² = Z₁² + Z₂² + … + Zₖ² 服從自由度為 k 的卡方分佈。

樣本變異數 s² 的抽樣分佈：(n-1)s²/σ² ~ χ²(n-1)，這是對 σ² 做推論的基礎。

🏭 品質工程應用

① 變異數的信賴區間：用 χ² 分佈計算 σ² 的 CI，判斷製程變異是否符合規格
② 適合度檢定（GoF）：觀測頻率 vs 理論頻率的吻合程度
③ 獨立性檢定：二維列聯表（如缺陷類型 vs 製程）

\[\chi^2_{\text{GoF}} = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}\] O = 觀測次數　E = 期望次數
df = 類別數 − 1（或 − 估計參數數 − 1）
與 t / F 的關係
t²(df=ν) ~ F(1, ν)　（t 的平方服從 F 分佈）
χ²(k)/k ~ F(k, ∞)　（卡方除以自由度趨近 F）
F(d₁,d₂) = [χ²(d₁)/d₁] / [χ²(d₂)/d₂]　（F 是兩個卡方比）

F 分佈的來源與品質工程應用
📐 數學由來

F 分佈是兩個獨立卡方變數除以各自自由度之比：

F = (χ²₁/d₁) / (χ²₂/d₂)

ANOVA 中，F = MS_Between / MS_Within。MS 是各自的變異數估計，H₀ 成立時兩者都估計同一個 σ²，F 應接近 1；若組間均值真的不同，分子會更大，F 遠大於 1。

🏭 品質工程應用

① ANOVA（變異數分析）：多組均值比較（→ 迴歸分析 tab）
② 迴歸整體顯著性：F 檢定整個迴歸模型是否有解釋力
③ 兩組變異數比較：舊製程 vs 新製程，σ₁²/σ₂² ~ F(n₁-1, n₂-1)
④ DOE 效應顯著性：每個因子的 MS 與誤差 MS 之比

三大分佈的連結
χ²(k) = k 個 Z² 的和
t(ν) = Z / √(χ²(ν)/ν)
F(d₁,d₂) = χ²(d₁)/d₁ ÷ χ²(d₂)/d₂
t²(ν) = F(1, ν)　← t 的平方就是 F

統計決策 Statistical Decision Making

假設檢定架構、p-value 的正確理解，以及信賴區間與配對比較。

核心直覺 — 怎麼決定 H₀ 和 H₁？

原則：把「你想要證明的事」放在 H₁
H₀ 是你試圖推翻的預設立場，H₁ 是你蒐集數據想支持的結論。

為什麼這樣設定？因為我們無法「接受」H₀，只能「無法拒絕」它。就像法庭上「無罪推定」——被告（H₀）預設無罪，除非有足夠證據（數據）才能定罪（拒絕 H₀）。

製造業情境範例：
① 供應商宣稱零件 > 10mm
H₀: μ ≤ 10mm（不相信供應商的宣稱）
H₁: μ > 10mm（你想驗證的事）→ 右尾

② 確認新製程比舊製程更穩定
H₀: σ_新 ≥ σ_舊（新製程沒有改善）
H₁: σ_新 < σ_舊（你想證明的改善）→ 左尾

③ 確認量具無 Bias
H₀: μ_bias = 0（量具準確）
H₁: μ_bias ≠ 0（想偵測任何方向的偏差）→ 雙尾
假設檢定五步驟

Step 1 — 建立假設
H₁ = 你想驗證的事；H₀ = H₁ 的反面（預設立場）

Step 2 — 選定顯著水準 α
通常設 α = 0.05（容忍 5% 的 Type I Error）

Step 3 — 計算檢定統計量
t = (x̄ - μ₀) / (s/√n)

Step 4 — 求 p-value
在 H₀ 成立的條件下，觀察到此結果（或更極端）的機率

Step 5 — 做出決策
p < α → 拒絕 H₀，支持 H₁  ｜  p ≥ α → 無法拒絕 H₀

兩類錯誤
H₀ 為真 H₀ 為假 拒絕 H₀ Type I Error(α) 正確 Power(1-β) 不拒絕 正確 (1-α) Type II Error(β)

Type I (α)：供應商零件其實 ≤ 10mm，我們卻誤判為 > 10mm → 錯誤接收

Type II (β)：供應商零件其實 > 10mm，我們卻說「無法證明」→ 錯誤拒收

Power (1-β)：真的有差異時能偵測到的機率。n 越大 → Power 越高。

降低 α → Type I ↓，但 Type II ↑
增加 n → 兩種錯誤都可以同時降低
單尾 vs 雙尾 — 由 H₁ 的方向決定

雙尾（Two-tailed）
H₁: μ ≠ μ₀
「有沒有差（不管方向）」
例：量具 Bias 偵測
拒絕域在兩端，各 α/2

左尾（Left-tailed）
H₁: μ < μ₀
「有沒有變小」
例：確認新製程 σ < 舊製程
拒絕域在左端

右尾（Right-tailed）
H₁: μ > μ₀
「有沒有變大」
例：驗證供應商宣稱 > 10mm
拒絕域在右端

p-value 互動視覺化
p-value 的正確解讀

正確定義：在 H₀ 為真的前提下，觀察到目前統計量（或更極端值）的機率。

常見誤解 ✗：p = 0.03 不是說「H₀ 有 3% 的機率為真」

常見誤解 ✗：p < 0.05 不代表「結果很重要」，只代表「統計上顯著」

常見誤解 ✗：p = 0.049 與 p = 0.051 實際上幾乎沒差

品質工程建議：p-value 搭配效果量（Effect Size）與信賴區間一起看，才有實務意義。

統計顯著 vs 實務顯著
情境：新製程 vs 舊製程重量差異
p = 0.001 → 統計上高度顯著 ✓
但差異只有 0.001 克
→ 實務上毫無意義 ✗

p = 0.08 → 統計不顯著
但差異達 5 克，成本影響巨大
→ 需增加樣本數再驗證

記住：統計顯著性由樣本數決定；實務重要性由工程判斷決定。

Before vs After — 分佈重疊圖

■ Before 分佈   ■ After 分佈   虛線 = 各自平均值。兩個分佈重疊越少、位移越大 → 差異越顯著。

t 分佈 — 拒絕域視覺化

橘色區域 = 拒絕域（各端 α/2）；橘色垂線 = 計算出的 t 值。t 落在拒絕域 → 拒絕 H₀。

各配對的差異值（Before − After）

綠色 = Before 大於 After；橘色 = After 大於 Before。配對 t 檢定的本質：檢定這些差異值的平均是否顯著不等於零。

變數關係分析 Correlation & Regression

最小平方法原理、散點圖、迴歸輸出解讀，以及品質工程實際應用場景。

最小平方法原理

給定 n 個數據點 (xᵢ, yᵢ)，最小平方法找出一條直線 Ŷ = β₀ + β₁X，使所有殘差的平方和（SSE）最小：

\[\text{SSE} = \sum_{i}(y_i - \hat{y}_i)^2 = \sum_{i}(y_i - \beta_0 - \beta_1 x_i)^2 \;\longrightarrow\; \text{最小化}\] \[\hat{\beta}_1 = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2} \qquad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}\]

「為什麼用平方？」→ 避免正負殘差互相抵消，且對大誤差懲罰更重（比絕對值更數學友善，可微分）。

OLS（Ordinary Least Squares，普通最小平方法）幾何意義

黃色垂直線 = 殘差（eᵢ = yᵢ − ŷᵢ）；OLS 找到一條使所有殘差平方和最小的直線。按「產生新數據」可反覆觀察。

OLS 的四個假設（LINE）

L — Linearity：X 與 Y 之間是線性關係

I — Independence：每個觀察值獨立（不適用時間序列相關）

N — Normality：殘差服從常態分佈

E — Equal Variance：殘差具等方差（Homoscedasticity）

檢驗方式：殘差圖（Residual Plot）是最重要的診斷工具。若殘差呈隨機分佈 → 假設成立；若有喇叭形或曲線 → 違反假設。

ANOVA — 變異數分析的核心邏輯

ANOVA（Analysis of Variance）回答一個問題：多組數據的平均值之間的差異，是真實的組間差異，還是只是隨機波動？

核心思路是把總變異（SST）拆成兩部分：

SST（總變異）= SS_Between（組間）+ SS_Within（組內）
F 統計量 = MS_Between / MS_Within
MS = SS / df（均方，Mean Square）
F 越大 → 組間差異相對組內雜訊越大 → 越顯著
\[F = \frac{SS_{Between}/(k-1)}{SS_{Within}/(N-k)} = \frac{MS_{Between}}{MS_{Within}}\] k = 組數　N = 總樣本數　H₀: μ₁ = μ₂ = ... = μₖ

品質工程應用：驗證不同供應商、換班、原料批次、設備的量測結果是否有顯著差異。與 SPC 的組間/組內概念完全一致。

量測系統分析 MSA — 用 Bias 的三種視角理解量具

① Bias 本身

Bias = 量測值 − 參考值的平均，反映量具的系統性偏差。

問題：「這支量具量出來的值，整體偏高還是偏低？」

工具：t 檢定（H₀: μ_bias = 0）

② Bias 隨量測範圍變化

Linearity = Bias 在不同參考值下是否一致，或隨量測值大小而線性改變。

問題：「量小的值準、量大的值就偏掉了嗎？」

工具：簡單線性迴歸（Bias vs 參考值）

③ Bias 隨時間變化

Stability = Bias 在不同時間點是否保持穩定，或隨使用時間漂移。

問題：「今天量準，一個月後還準嗎？」

工具：I-MR 管制圖（Bias vs 時間）

① Bias — 量具的固定系統誤差

在同一個參考標準件上重複量測多次，計算所有量測值與標準值的差（Bias），再用 t 檢定判斷 Bias 是否顯著不等於零。

\[\text{Bias}_i = \text{量測值}_i - \text{參考值} \qquad \bar{d} = \frac{\sum \text{Bias}_i}{n}\] \[t = \frac{\bar{d}}{s_d/\sqrt{n}} \quad \text{H}_0: \mu_\text{bias} = 0\] p < 0.05 → Bias 顯著存在 → 量具需要校正（歸零或補償）
按「計算」開始

橘虛線 = 參考值；藍色分佈 = 量測值的分佈；綠色區間 = 95% CI for Bias。CI 不包含零 → Bias 顯著。

② Linearity — Bias 隨量測範圍的變化

在量具的整個量測範圍內選取多個參考標準件（涵蓋低中高值），各量測多次，計算每個參考值對應的 Bias，再對參考值做迴歸。

斜率 β₁ ≠ 0 → Bias 隨量測範圍線性變化 → Linearity 問題。斜率為正代表量測大值時偏差更大；斜率為負代表量測小值時偏差更大。

\[\text{Bias} = \hat\beta_0 + \hat\beta_1 \times \text{參考值}\] \[\%\text{Linearity} = |\hat\beta_1| \times 100\%\] β₁ = 0：不同量測範圍的 Bias 一致（理想）
|%Linearity| < 5%：優　< 10%：可接受　≥ 10%：不合格
按「計算」開始

X 軸 = 參考標準值（量測範圍）；Y 軸 = Bias 值。
水平綠線 = Bias = 0（理想）；橘色迴歸線斜率越大 → Linearity 問題越嚴重。

③ Stability — Bias 隨時間的變化

定期（每天/每週）量測同一個標準件，記錄 Bias，繪製 I-MR 管制圖。若 Bias 的 I 圖出現趨勢、偏移或超界 → 量具已發生漂移，需重新校正。

常見漂移原因：

• 緩慢漂移：機械磨耗、感測器老化、溫漂累積

• 突然偏移：量具受碰撞損傷、更換電池或零件

與 SPC 管制圖的連結：Stability 圖本質上就是 Bias 的 I 圖，同樣用 Nelson Rules 判讀。管制圖穩定 → 量具在校正週期內可信。

Bias 的 I-MR 管制圖（Y 軸 = Bias 值，X 軸 = 時間點）

水平綠線 = Bias = 0（理想基準）；橘虛線 = 管制界限

三個視角的總整理
■ Bias　在固定量測點重複量測 → 量測值的分佈整體偏離參考值多少？
■ Linearity　跨越量測範圍比較 Bias → Bias 隨量測值大小線性變化嗎？（迴歸斜率）
■ Stability　跨越時間比較 Bias → Bias 隨使用時間漂移嗎？（管制圖趨勢）
IATF 7.1.5.1：校正需確保 Bias 在可接受範圍，Stability 定期驗證。 7.1.5.2：MSA 是 PPAP 必要項目。

🔮 漏斗實驗（Funnel Experiment）— 過度調整的代價

1989 年，Deming 用漏斗和彈珠演示：若每次落點偏離目標就調整漏斗位置（過度干預），最終散佈反而比完全不動還大。

四條規則：

Rule 1：永不調整 → 穩定，變異最小（正確做法）

Rule 2：以上次落點為基準調整 → 振盪加劇

Rule 3：以原點為基準調整 → 不穩定發散

Rule 4：每次移到上次落點 → 指數級偏移

漏斗移動過程（前 8 步）—— ▼ 橘色三角 = 漏斗位置， ● 藍點 = 彈珠落點， 虛線 = 目標原點

每格 = 一次試驗。漏斗位置（橘）→ 彈珠落點（藍）→ 根據規則決定下一步漏斗位置

🏭 IATF 16949 連結 — 條文 10.2.3 & 8.5.6

IATF 16949 條文 10.2.3（Problem Solving）要求：採取矯正措施前必須先確認問題根本原因。若未區分普通/特殊原因，直接調整製程設定值（Tampering），反而違反此條文精神。

條文 8.5.6（Change Control）：製程設定值的更改必須有書面授權，不能由操作員自行依管制圖數值波動隨意調整。SPC 管制圖正是判斷「是否需要授權調整」的依據。

🔴 紅珠實驗（Red Bead Experiment）

Deming 的另一個著名演示：一桶含 80% 白珠（良品）和 20% 紅珠（不良品）的珠子，讓工人用固定的槳挖取 50 顆，紀錄紅珠數。

🎯 實驗結論

• 工人無論多努力，紅珠比例由系統決定，個人無法控制
• 表現「好」的工人是運氣好，不是技術好
• 獎懲個人績效、口號激勵完全無效
• 要降低不良率，只能改變珠桶本身（系統）

🏭 IATF 16949 連結 — 條文 7.3 & 6.1

條文 7.3（Awareness）：組織需確保人員了解品質目標與個人工作的關聯，但個人意識無法彌補系統設計的缺陷。
條文 6.1（Risk & Opportunity）：識別系統性風險是管理者的責任，等同紅珠實驗中「只有管理者能換掉紅珠」。

普通原因 vs 特殊原因 — Deming 核心區分 + IATF 16949 條文對應
🔵 普通原因（Common Cause）

定義：系統設計固有的、可預測的隨機變異
例子：原料批次差異、環境溫濕度波動、設備自然磨耗
對策：管理者改善製程設計/系統/設備
管制圖：所有點在管制界限內隨機分佈
IATF 條文：8.5.1.1 管制計畫需涵蓋普通原因變異的監控方法

🔴 特殊原因（Special Cause）

定義：非系統性、可識別的外部干擾
例子：刀具突然磨損、換批原料、操作員失誤
對策：現場人員立即停機調查並消除
管制圖：超界、趨勢、非隨機模式
IATF 條文：10.2.3 特殊原因出現需啟動問題解決流程並記錄根本原因

⚠️ 過度調整（Tampering）= IATF 16949 違規風險

把普通原因當特殊原因處理，每次 Xbar 稍微偏移就調整機台設定值（未超出管制界限）：
→ 變異增加而非減少（漏斗實驗 Rule 2 效應）
→ 違反 IATF 8.5.6（未經授權更改製程設定值）
→ 違反 IATF 10.2.3（矯正措施未基於根本原因分析）
→ 客戶稽核時，「操作員自行調機的紀錄」是重大不符合項的常見來源

W. Edwards Deming 博士
🎯 核心理念

「94% 的品質問題來自系統，只有 6% 來自個人。」— Deming

Deming 1950 年代赴日本講學，深刻影響豐田生產系統（TPS）與全面品質管理（TQM）。他認為品質不靠「檢驗」，而靠系統設計內建。

Deming 14 點（品質相關）

Point 1：建立持久改善品質的目標

Point 3：廢除依賴大量檢驗，品質應設計於產品中

Point 5：持續改善生產與服務系統

Point 10：廢除對員工的口號與目標（Tampering 的根源）

Point 11：廢除數字配額制度，改用統計方法管理

EWMA 概念 — 指數加權移動平均

傳統 Xbar 圖對每個子群的權重相同，對小偏移不敏感。 EWMA（Exponentially Weighted Moving Average）給近期數據較高權重、舊數據指數遞減， 能更快偵測到製程均值的小幅漂移（通常 1～1.5σ 的偏移）。

\[z_t = \lambda x_t + (1-\lambda)\,z_{t-1}\] \[\sigma_{z_t} = \sigma\sqrt{\frac{\lambda}{2-\lambda}\!\left[1-(1-\lambda)^{2t}\right]}\] \[UCL = \mu_0 + L\,\sigma_{z_t} \qquad LCL = \mu_0 - L\,\sigma_{z_t}\] λ（lambda）= 平滑參數，0 < λ ≤ 1，建議 0.05～0.25
L = 管制界限寬度係數，建議搭配 λ 查表（常用 L=2.7～3.0）
λ=1 時退化為 Shewhart Xbar 圖；λ 越小對小偏移越敏感
λ 選擇指引：
λ = 0.05～0.10：偵測極小偏移（<1σ），對大偏移反應慢
λ = 0.10～0.20：最常用，平衡小偏移靈敏度與誤報率
λ = 0.20～0.40：介於 EWMA 與 Shewhart 之間
λ = 1.00：等同 Shewhart Xbar 圖
EWMA vs Xbar 圖比較
Shewhart Xbar 圖
只使用當前子群數據
對大偏移（>2σ）極靈敏
小偏移可能需多點才偵測到

EWMA 管制圖
使用所有歷史數據（指數加權）
對小偏移（1～1.5σ）更靈敏
ARL（平均連串長度）表現優異
常與 CUSUM 搭配使用
🏭 品質工程應用

化工製程的微量濃度漂移、半導體蝕刻深度的緩慢趨勢、醫療器材的尺寸微小偏移——這些場景偏移量小但累積影響大，EWMA 是最適合的工具。IATF 16949 的特殊特性（SC/CC）監控也常使用 EWMA 配合更嚴格的 L 值。

核心術語

因子 Factor：可控制的輸入變數

水準 Level：因子的設定值（+1/-1 編碼）

回應 Response：量測的輸出

主效應：因子從低到高水準的平均影響

交互作用：一因子的效應受另一因子影響

\[2^k \text{ 全因子：}k\text{ 個因子，各 2 水準}\quad (k=2\!:\!4\text{ 次},\;k=3\!:\!8\text{ 次},\;k=4\!:\!16\text{ 次})\] \[\text{Effect}(A) = \bar{Y}_{A+} - \bar{Y}_{A-}\]
DOE 的三大優勢

① 同時研究多個因子
一次實驗涵蓋所有因子組合，不需要分批逐一調整。

② 偵測交互作用
當 A 因子的效應受 B 因子影響時，只有 DOE 能夠發現——這是最有價值的資訊。

③ 資訊量最大化
2³ 全因子 8 次實驗，可以估計 3 個主效應 + 3 個二因子交互作用 + 1 個三因子交互作用，是效率最高的實驗設計方式。

優化目標 — 望大、望小、望目

DOE 的最終目的是找出最佳因子水準組合，但「最佳」的定義取決於回應變數的特性：

望大（Larger-is-Better）

定義：回應值越大越好，無上限

例子：拉伸強度、焊接強度、電池壽命、表面硬度

判斷方式：Effect(A) 為正 → 因子 A 設高水準 (+) 可增大回應值

望小（Smaller-is-Better）

定義：回應值越小越好，最小為零

例子：尺寸偏差、不良率、縮水率、表面粗糙度

判斷方式：Effect(A) 為正 → 因子 A 設低水準 (−) 可減小回應值

望目（Nominal-is-Best）

定義：回應值靠近特定目標值（有上下規格）

例子：電阻值、配合間隙、溫度設定、濃度

判斷方式：先用主效應圖找到最接近目標值的水準組合，再最小化變異

如何用效應圖判斷因子水準設定：
望大：Effect 為正 → 設高水準；Effect 為負 → 設低水準（讓回應值上升）
望小：Effect 為正 → 設低水準；Effect 為負 → 設高水準（讓回應值下降）
望目：找到使回應值最接近目標的水準，不顯著的因子設在操作成本較低的水準

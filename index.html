統計決策 Statistical Decision Making

信賴區間估計與配對比較檢定。用數據說話，做出有把握的決策。

信賴區間計算機
按「計算」開始
CI = x̄ ± t(α/2, n-1) × s/√n
視覺化

橘線 = 點估計，藍色區間 = 信賴範圍。信心水準越高，區間越寬——精確度與確定性的取捨。

配對 t 檢定計算機

輸入配對前後數據（以逗號分隔），例如：新舊製程的同一批產品量測值

按「執行」開始
差異值圖
假設檢定邏輯

H₀（虛無假設）：預設為「沒有差異」。我們試圖用數據推翻它。

H₁（對立假設）：我們想支持的結論。

p-value：假設 H₀ 成立，觀察到此數據（或更極端）的機率。p < α → 拒絕 H₀。

α = 0.05 → 有 5% 機率犯 Type I Error
Type I Error: 真的沒差，卻說有差 (False Positive)
Type II Error: 真的有差，卻說沒差 (False Negative)
信賴區間 vs 假設檢定

兩者本質相同，只是呈現方式不同：

• 假設檢定：回答「有沒有差」→ 是/否決策

• 信賴區間：回答「差多少」→ 量化估計，更有實務價值

製造業建議：優先使用 CI，因為工程師需要知道「差了幾 mm」，而非只知道「有差」。

相關係數模擬器
相關強度 r 0.80
樣本數 n 30
r = Σ[(xᵢ-x̄)(yᵢ-ȳ)] / √[Σ(xᵢ-x̄)²·Σ(yᵢ-ȳ)²]
r = 0.80 → 強正相關

⚠️ 相關 ≠ 因果。高 r 值只說明線性關係，不代表 X 導致 Y。

R²（決定係數）：模型解釋了多少變異。R²=0.85 → X 解釋了 85% 的 Y 變異。

係數 p-value：X 對 Y 的影響是否顯著。p<0.05 → 顯著。

統計製程管制 SPC

管制圖選擇、判讀，以及區分普通原因與特殊原因變異。

Xbar-R 管制圖模擬器
管制圖選擇指南

計量值（連續數據）

• Xbar-R：子群大小 2–8，最常用

• Xbar-S：子群大小 ≥ 9，變異估計更精確

• I-MR（X-MR）：子群大小 = 1（每次一筆）

計數值（離散數據）

• p chart：不良率（n 可變）

• np chart：不良數（n 固定）

• c chart：缺陷數（固定樣本）

• u chart：每單位缺陷數（樣本可變）

管制界限（Xbar-R）：
UCL_X = X̄ + A₂R̄
LCL_X = X̄ - A₂R̄
UCL_R = D₄R̄
LCL_R = D₃R̄

A₂(n=5)=0.577, D₃=0, D₄=2.114

⚠️ 管制界限 ≠ 規格界限（Spec Limit）。管制圖反映製程自然變異，規格界限是客戶需求。

Nelson / Western Electric 判讀規則

Rule 1：1 點超出 UCL 或 LCL（±3σ）

Rule 2：連續 9 點在中心線同側

Rule 3：連續 6 點持續上升或下降（趨勢）

Rule 4：連續 14 點交互上下（振盪）

Rule 5：連續 2/3 點超出 ±2σ（同側）

Rule 6：連續 4/5 點超出 ±1σ（同側）

Rule 7：連續 15 點在 ±1σ 內（層化）

Rule 8：連續 8 點在 ±1σ 外

普通原因變異（Common Cause）：
→ 系統固有，可預測，需改變
→ 對策：改善製程設計/系統

特殊原因變異（Special Cause）：
→ 非預期，有特定原因
→ 對策：找出並消除該原因

⚠️ 常見錯誤：把普通原因當特殊原因處理（反應過度），或把特殊原因忽視（反應不足），都會使製程變差。

實驗設計 Design of Experiments

系統化地找出關鍵因子，最大化資訊量，最小化實驗成本。

核心術語

因子 Factor：可控制的輸入變數（如：溫度、壓力、材料）

水準 Level：因子的設定值（如：高/低，即 +1/-1）

回應 Response：量測的輸出（如：強度、良率、週期時間）

主效應 Main Effect：單一因子從低水準到高水準的平均影響

交互作用 Interaction：一個因子的效應受另一個因子影響

2ᵏ 全因子設計：k 個因子，各 2 個水準
k=2: 4 次實驗 | k=3: 8 次 | k=4: 16 次
為什麼不能「一次改一個」(OFAT)?

傳統 OFAT（One Factor At a Time）的問題：

• 無法偵測交互作用：A 與 B 可能互相影響

• 效率低：需要更多實驗才能涵蓋因子空間

• 結論可能錯誤：最優解可能在非測試的組合

DOE 優點：同時研究多個因子 + 偵測交互作用 + 用更少實驗得到更多資訊

2³ 全因子設計表
輸入回應值，計算主效應

請先產生設計表，再輸入各執行的回應值（強度 MPa）

效應分析視覺化
Pareto 圖解讀

效應圖（Pareto of Effects）按影響大小排列，紅線為顯著性門檻（α=0.05）。

超過紅線的因子/交互作用為顯著效應，是優化的重點。

主效應圖：顯示單一因子從低到高的平均回應變化。

交互作用圖：若線條交叉或不平行，表示有顯著交互作用——此時不能單獨解讀主效應。

Effect(A) = Ȳ(A+) - Ȳ(A-)
即：A 高水準平均 - A 低水準平均
